# بازی Shahd Drone

نسخه اولیه قابل بازی اندروید با نمای سینمایی، HUD، رادار، کنترل لمسی و قفل هدف.

## گرفتن APK بدون کامپیوتر
1. یک حساب GitHub بساز.
2. یک Repository جدید بساز.
3. تمام فایل‌های این پروژه را Upload کن.
4. از تب Actions، ورک‌فلو `Build Shahd Drone APK` را اجرا کن.
5. بعد از پایان Build، از بخش Artifacts فایل `Shahd-Drone-debug-apk` را بگیر.
6. APK را روی گوشی نصب کن.

این روش نیاز به نصب Android Studio روی گوشی یا کامپیوتر ندارد؛ کامپایل روی سرور GitHub انجام می‌شود.
